# Silicon Atlas

After reading *Chip War*, I realized that just reading about the semiconductor industry in the *Financial Times* or the *Wall Street Journal* wasn't enough to really grasp how insane the global supply chain is, I needed to see it. **Silicon Atlas** is my way of mapping that out. It’s a React 19 project built with D3 and Tailwind that starts with a timeline of how we got here, but I’m working toward an interactive map that visualizes the actual flow of the industry. It’s still pretty early days, the folder structure is a bit of a mess, and I’m mostly using it as a place to organize my thoughts and eventually yap about chips in a blog section, but it’s a fun way to turn a deep dive into the "oil of the 21st century" into something tangible.
